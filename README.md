
## "Розміщення шахових фігур та ігри на дошці"

---

## 1. Опис проекту

Програма реалізує п'ять алгоритмічних задач на класичній шаховій дошці 8×8 з графічним інтерфейсом на Python/tkinter.

## 2. Що можна робити

### Вкладка "Шахові фігури" (Тура, Слон, Ферзь)
- Розміщення фігури за координатами (a1-h8)
- Автоматична перевірка атаки іншими фігурами
- Виведення попередження з вказанням фігури-агресора
- Видалення фігури за координатами
- Підсвічування атакованих клітинок
- Історія всіх операцій

### Вкладка "Шашки"
- Розміщення звичайної шашки або дамки
- Перевірка атаки з урахуванням порожньої клітинки за суперником
- Шашка б'є на 1 клітинку по діагоналі
- Дамка б'є на будь-яку відстань по діагоналі
- Кольорова візуалізація (червоні шашки, чорні дамки)

### Вкладка "Реверсі"
- Покрокова гра (чорні перші)
- Автоматичне перевертання фішок суперника за 8 напрямками
- Підсвітка можливих ходів зеленим кольором
- Лічильник чорних та білих фішок
- Автовизначення переможця
- Клік мишкою для вибору клітинки

---

## 3. Ключові функції та відповідальність

### Клас `ChessTab` (шахові фігури)

| Функція | Відповідає за |
|---------|---------------|
| `parse_cell()` | Перетворює "a1" в (0,0) |
| `occupied_all()` | Збирає всі зайняті клітинки |
| `can_place_rook()` | Перевіряє атаку тури |
| `can_place_bishop()` | Перевіряє атаку слона |
| `can_place_queen()` | Перевіряє атаку ферзя |
| `attacked_by_piece()` | Обчислює атаковані клітинки |
| `check_and_place()` | Розміщує фігуру на дошку |
| `remove_piece()` | Видаляє фігуру з дошки |
| `draw_board()` | Малює дошку та фігури |

### Клас `CheckersTab` (шашки)

| Функція | Відповідає за |
|---------|---------------|
| `_can_capture()` | Перевіряє можливість побиття |
| `_get_attacked_cells()` | Обчислює клітинки під атакою |
| `can_place()` | Перевіряє чи можна поставити |
| `check_and_place()` | Розміщує шашку/дамку |
| `remove_piece()` | Видаляє шашку/дамку |
| `draw_board()` | Малює доску та шашки |

### Клас `ReversiTab` (реверсі)

| Функція | Відповідає за |
|---------|---------------|
| `get_valid_moves()` | Знаходить можливі ходи |
| `get_flipped_pieces()` | Обчислює які фішки перевернути |
| `make_move()` | Виконує хід та перевертає |
| `reset_game()` | Починає нову гру |
| `on_canvas_click()` | Реагує на клік мишкою |
| `draw_board()` | Малює дошку та фішки |

### Головна функція

| Функція | Відповідає за |
|---------|---------------|
| `main()` | Запускає програму |
