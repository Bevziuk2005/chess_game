# README.md - Повна документація проекту

## "Розміщення шахових фігур та ігри на дошці"

---

## 1. Опис проекту

Програма реалізує п'ять алгоритмічних задач на класичній шаховій дошці 8×8 з графічним інтерфейсом на Python/tkinter.

## 2. Що можна робити

### Вкладка "Шахові фігури" (Тура, Слон, Ферзь)
- Розміщення фігури за координатами (a1-h8)
- Автоматична перевірка атаки іншими фігурами
- Виведення попередження з вказанням фігури-агресора
- Видалення фігури за координатами
- Підсвічування атакованих клітинок
- Історія всіх операцій

### Вкладка "Шашки"
- Розміщення звичайної шашки або дамки
- Перевірка атаки з урахуванням порожньої клітинки за суперником
- Шашка б'є на 1 клітинку по діагоналі
- Дамка б'є на будь-яку відстань по діагоналі
- Кольорова візуалізація (червоні шашки, чорні дамки)

### Вкладка "Реверсі"
- Покрокова гра (чорні перші)
- Автоматичне перевертання фішок суперника за 8 напрямками
- Підсвітка можливих ходів зеленим кольором
- Лічильник чорних та білих фішок
- Автовизначення переможця
- Клік мишкою для вибору клітинки
