
## "Розміщення шахових фігур та ігри на дошці"

---

## 1. Опис проекту

Програма реалізує п'ять алгоритмічних задач на класичній шаховій дошці 8×8 з графічним інтерфейсом на Python/tkinter.

## 2. Що можна робити

### Вкладка "Шахові фігури" (Тура, Слон, Ферзь)
- Розміщення фігури за координатами (a1-h8)
- Автоматична перевірка атаки іншими фігурами
- Виведення попередження з вказанням фігури-агресора
- Видалення фігури за координатами
- Підсвічування атакованих клітинок
- Історія всіх операцій

### Вкладка "Шашки"
- Розміщення звичайної шашки або дамки
- Перевірка атаки з урахуванням порожньої клітинки за суперником
- Шашка б'є на 1 клітинку по діагоналі
- Дамка б'є на будь-яку відстань по діагоналі
- Кольорова візуалізація (червоні шашки, чорні дамки)

### Вкладка "Реверсі"
- Покрокова гра (чорні перші)
- Автоматичне перевертання фішок суперника за 8 напрямками
- Підсвітка можливих ходів зеленим кольором
- Лічильник чорних та білих фішок
- Автовизначення переможця
- Клік мишкою для вибору клітинки

## Документація функції підсвічування зайнятих клітинок

### Назва функції

`draw_board()` (у класах `ChessTab` та `CheckersTab`)

### Що робить

Підсвічує клітинки, які вже зайняті фігурами, окремим кольором.

---

### Як працює (покроково)

#### Крок 1. Збір зайнятих позицій

```python
occupied = self.occupied_all()
```

Функція `occupied_all()`:

* проходить по всіх фігурах у `self.placed`
* повертає множину координат усіх зайнятих клітинок

Приклад:

```python
{(0, 0), (3, 4), (7, 7)}
```

---

#### Крок 2. Перебір всіх клітинок дошки

```python
for row in range(8):
    for col in range(8):
        pos = (col, row)
```

Відбувається повний обхід дошки `8 × 8`.

Для кожної клітинки створюється координата:

```python
pos = (col, row)
```

---

#### Крок 3. Визначення кольору зайнятої клітинки

```python
if pos in occupied:
    if pos in highlight:
        color = OCCUPIED_ATTACKED
    else:
        color = OCCUPIED_SQUARE
```

Логіка роботи:

* якщо клітинка **зайнята**, вона підсвічується синім кольором
* якщо клітинка **одночасно зайнята й атакована**, використовується темніший синій колір
* якщо клітинка **порожня**, використовується стандартний колір дошки

---

#### Крок 4. Малювання клітинки

```python
self.canvas.create_rectangle(
    x1,
    y1,
    x2,
    y2,
    fill=color,
    outline="black"
)
```

Клітинка малюється на canvas із визначеним кольором.

---

### Кольори підсвічування

| Ситуація                     |             Колір (HEX) | Опис                      |
| ---------------------------- | ----------------------: | ------------------------- |
| Клітинка зайнята             |               `#7FA8D6` | Синій колір               |
| Клітинка зайнята + атакована |               `#6E9FD1` | Темніший синій            |
| Клітинка порожня             | `#F0D9B5` або `#B58863` | Стандартні шахові кольори |

---

### Схема роботи

```text
зайняті позиції = {(0,0), (3,4), (7,7)}
        ↓
перебираємо всі 64 клітинки
        ↓
для кожної клітинки:
    якщо позиція в зайнятих:
        якщо ще й атакована → темно-синій
        інакше → синій
    інакше:
        стандартний шаховий колір
```

### Приклад візуалізації

```text
Дошка (фрагмент):

   a   b   c   d
8  ██  ██  ██  ██

5  ██  ██  ██  ██

🟦 = зайнята клітинка
██ = порожня клітинка
```

### Ключові змінні

| Змінна              | Значення     | Призначення                           |
| ------------------- | ------------ | ------------------------------------- |
| `OCCUPIED_SQUARE`   | `"#7FA8D6"`  | Колір зайнятої клітинки               |
| `OCCUPIED_ATTACKED` | `"#6E9FD1"`  | Колір зайнятої та атакованої клітинки |
| `occupied`          | `set[tuple]` | Множина координат зайнятих клітинок   |
| `highlight`         | `set[tuple]` | Множина координат атакованих клітинок |
